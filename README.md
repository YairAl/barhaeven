# Bar HaEven

דף הנחיתה של בר האבן – הבר הקהילתי של אבן יהודה (Next.js, static export ל-GitHub Pages).

- כל הטקסטים, לוח ההופעות, המוצרים ופרטי הקשר נמצאים ב-`src/content.ts`.
- תמונות של אבן יהודה: שימו את הקבצים ב-`public/even-yehuda/` והוסיפו אותם ל-`evenYehudaPhotos` ב-`src/content.ts` (עם `credit` לקרדיט הצלם). הרצועה בסקשן "אבן יהודה" מוצגת רק כשהרשימה לא ריקה.

```bash
npm ci
npm run dev
```
